# 디시클리너 (디시 클리너)

**디시클리너**는 본인의 디시인사이드 갤로그에 작성한 게시글과 댓글을 편리하게 정리할 수 있는 무료 오픈소스 프로그램입니다.

Android, Windows, macOS를 지원하며, 갤러리별 선택 삭제와 중단 작업 이어하기, Android 백그라운드 실행, 수동·자동 캡챠 해결 기능을 제공합니다.

> 본인 계정의 게시글과 댓글을 관리하는 용도로만 사용하세요. 디시클리너는 디시인사이드의 공식 프로그램이 아닙니다.

## 디시클리너 다운로드

최신 버전은 GitHub Releases에서 무료로 다운로드할 수 있습니다.

➡️ **[디시클리너 최신 버전 다운로드](https://github.com/dccleaner3/dccleaner/releases/latest)**

| 지원 운영체제 | 제공 형태 |
| --- | --- |
| Android | APK |
| Windows | 데스크톱 앱 |
| macOS | 데스크톱 앱 |
| iOS | 지원하지 않음 |

## 주요 기능

- **게시글·댓글 정리**: 내 갤로그에 작성한 게시글과 댓글을 종류별로 삭제할 수 있습니다.
- **갤러리별 선택 삭제**: 활동한 갤러리 중 원하는 갤러리의 기록만 선택해 정리할 수 있습니다.
- **게시글 보존 조건**: 일정 추천 수 또는 댓글 수 이상인 게시글은 남길 수 있습니다.
- **댓글 상세 필터**: 내가 작성한 글의 댓글, 디시콘 댓글, 정규식과 일치하는 댓글만 선택할 수 있습니다.
- **기간 조건**: 지정한 일수 이상 지난 게시글과 댓글만 삭제할 수 있습니다.
- **중단 작업 이어하기**: 앱 종료, 네트워크 오류 또는 캡챠로 중단된 작업을 저장하고 이어서 진행할 수 있습니다.
- **백그라운드 실행**: Android에서는 화면을 끄거나 다른 앱을 사용하는 동안에도 삭제 작업이 계속됩니다.
- **캡챠 대응**: 갤로그에서 직접 캡챠를 해결하거나 2Captcha API를 이용해 자동으로 처리할 수 있습니다.

## 사용 방법

1. GitHub Releases에서 운영체제에 맞는 최신 버전을 다운로드합니다.
2. 디시인사이드 계정으로 로그인합니다.
3. 삭제할 항목과 갤러리, 보존 조건을 선택합니다.
4. 삭제 시작을 누르고 진행 상황을 확인합니다.

화면별 설명과 캡챠 해결 방법은 **[디시클리너 사용 방법](cleaner.html)**에서 확인할 수 있습니다.

## 자주 묻는 질문

### 디시클리너는 무료인가요?

네. 디시클리너 프로그램은 무료로 배포되는 오픈소스입니다. 선택 기능인 2Captcha 자동 해결 서비스를 사용하면 해당 서비스 이용료가 별도로 발생할 수 있습니다.

### 디시클리너는 어떤 운영체제를 지원하나요?

Android, Windows, macOS를 지원합니다. iOS용 앱은 제공하지 않습니다.

### 모든 게시글과 댓글을 한 번에 삭제해야 하나요?

아닙니다. 게시글과 댓글을 구분하고, 갤러리와 기간, 추천 수, 댓글 수 등의 조건을 지정해 원하는 항목만 정리할 수 있습니다.

### 삭제 도중 앱을 종료하면 처음부터 다시 해야 하나요?

중단된 작업과 삭제 대기열이 저장되므로 지원되는 상황에서는 이어서 진행할 수 있습니다.

### 로그인 정보는 어디에 사용되나요?

로그인 정보는 본인 계정의 게시글과 댓글을 조회하고 삭제 요청을 처리하는 데 사용됩니다. 저장소의 소스 코드를 직접 확인할 수 있습니다.
